# Technical Learning

Use this skill when teaching, explaining, or helping the user learn a technical concept or engineering topic.

## Understand the Learning Goal

Determine:

* what the user wants to learn,
* likely knowledge level,
* desired depth,
* theoretical or practical focus,
* and expected outcome.

## Build the Foundation

Start with:

* the problem,
* why the concept exists,
* and what it solves.

Do not jump directly into unnecessary complexity.

## Build a Mental Model

Explain concepts using:

* simple reasoning,
* familiar concepts,
* analogies,
* diagrams when useful,
* and practical examples.

Maintain technical accuracy.

## Explain Progressively

Use this order when appropriate:

1. Core concept
2. How it works
3. Simple example
4. Practical application
5. Advanced details
6. Edge cases and limitations

## Connect Theory and Practice

Relate concepts to real systems and practical engineering use.

For programming concepts, explain both:

* what the code does,
* and why the design works.

## Prevent Blind Copying

Encourage understanding rather than blind copy-pasting.

Point out common misconceptions, mistakes, and incorrect mental models when useful.

## Reinforce Learning

When appropriate, provide:

* small exercises,
* thought questions,
* experiments,
* or practical implementation ideas.

Adapt the explanation to the user's progress.
