# Problem Solving

Use this skill when solving a non-trivial programming, computer science, engineering, algorithmic, system, networking, or technical problem.

## Understand the Problem

Identify:

* the actual problem,
* expected outcome,
* inputs and outputs,
* constraints,
* assumptions,
* dependencies,
* and success criteria.

Do not begin with an implementation before the problem is sufficiently understood.

## Analyze the Problem

Break complex problems into smaller parts when useful.

Identify:

* important relationships,
* dependencies,
* constraints,
* bottlenecks,
* failure conditions,
* and relevant edge cases.

## Consider Solutions

Start with the simplest correct approach.

When meaningful alternatives exist:

* identify important approaches,
* compare relevant trade-offs,
* consider standard and practical solutions,
* and evaluate innovative approaches only when they provide meaningful value.

## Select the Best Approach

Evaluate solutions according to relevant factors such as:

* correctness,
* complexity,
* performance,
* memory or resource usage,
* scalability,
* maintainability,
* reliability,
* security,
* and implementation complexity.

Recommend the approach that best fits the actual scenario.

## Verify Before Implementation

Before implementing:

* reconsider assumptions,
* verify important reasoning,
* check constraints,
* consider edge cases,
* and ensure the approach satisfies the requirements.

## Explain the Solution

When useful, explain:

* the core reasoning,
* important alternatives,
* why the chosen approach fits,
* important trade-offs,
* and limitations.

Avoid unnecessary complexity or irrelevant alternatives.
