# Implementation

Use this skill when implementing, modifying, refactoring, or integrating significant code.

## Inspect Before Implementing

Inspect relevant:

* files,
* modules,
* architecture,
* interfaces,
* dependencies,
* configuration,
* tests,
* and project conventions.

Understand how the change fits into the existing system.

## Identify Impact

Determine:

* affected files,
* affected components,
* integration points,
* dependencies,
* possible regressions,
* security implications,
* and documentation needs.

## Design the Change

Before significant implementation:

* define the approach,
* keep responsibilities clear,
* minimize unnecessary changes,
* and choose an implementation proportional to the requirements.

## Implement

Write code that is:

* correct,
* readable,
* maintainable,
* idiomatic,
* modular,
* and appropriate to the existing project.

Avoid unnecessary duplication, abstraction, complexity, and unrelated changes.

Handle expected errors and relevant edge cases.

Validate external or untrusted input when appropriate.

## Review After Implementation

Inspect affected and related areas for:

* integration problems,
* regressions,
* broken assumptions,
* error handling issues,
* security concerns,
* and maintainability problems.

Use appropriate verification tools when available.

Do not claim verification unless it actually occurred.
